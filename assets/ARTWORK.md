# Outlands artwork

`wallpapers/outlands-monolith-v1.png` is portrait artwork generated with the
built-in imagegen tool for this project, using the owner's existing Outlands
Hub architectural artwork as the visual reference. The source hub, original
reference image, and private network configuration are not bundled here.

Prompt: Create a tall Outlands-style scene with immense charcoal-black
monolithic fortress towers, deep red vertical illumination and restrained red
mist. Use a dark reflective geometric ground plane with sparse cyan traces.
Leave dark space for a clock and launcher controls. Palette: near black
`#080B11`, charcoal, red, and sparse cyan `#62E8F5`. No text, logos, people,
watermarks, or interface elements. Opaque background.

The wallpaper is a visual asset. It does not depict live infrastructure or
device status. The application uses native controls for readable text and
actual device information.
